# Windows Meeting Assistant

Система автоматической записи, транскрибации и структурирования протоколов встреч для операционной системы Windows.

## Назначение и функциональные возможности

Приложение выполняет непрерывный фоновый мониторинг, запись и обработку аудиоматериалов рабочих встреч.

Основные функции:

* **Двухканальный захват аудио:** Запись голоса пользователя с микрофона и звука собеседников (через WASAPI loopback) в единый моно-аудиопоток 16 kHz.
* **Интеграция с Microsoft Outlook:** Автоматическое извлечение темы встречи, состава участников, организатора и описания из календаря Outlook через MAPI API.
* **Локальная транскрибация:** Преобразование речи в текст с помощью библиотеки Faster-Whisper на базе графического ускорителя (CUDA).
* **Генерация саммари:** Формирование краткого содержания, ключевых тезисов и списка поручений (Action Items) с использованием локальной языковой модели в Ollama.
* **Экспорт в Obsidian:** Автоматическое создание структурированных Markdown-заметок с YAML-метаданными в заданной директории Obsidian Vault.
* **Ротация архива:** Автоматическая очистка исходных аудиофайлов старше 7 дней из локального архива.

---

## Архитектура и стек технологий

Проект реализован на языке Python и состоит из трех основных компонентов:

1. **Графический интерфейс (`src/ui.py`):** Построен на базе библиотеки CustomTkinter. Обеспечивает управление записью, интеграцию с Outlook и отображение логов/состояния очереди.
2. **Модуль записи (`src/recorder.py`):** Использует PyAudioWPatch для параллельного захвата микрофона и системного звука (WASAPI loopback) с последующим микшированием в WAV 16 kHz mono.
3. **Фоновый воркер (`src/worker.py`):** Реализован в отдельном потоке daemon. Отвечает за предзагрузку LLM в VRAM, обработку очередности входящих файлов, вызов Faster-Whisper, отправку запросов к Ollama API и запись результатов в Obsidian.

**Стек технологий:**

* Python 3.10+
* CustomTkinter
* PyAudioWPatch (WASAPI Loopback)
* Faster-Whisper (`large-v3`, CUDA, float16)
* Ollama (`gemma4-64k-q4:latest`)
* PyWin32 (Win32com Outlook Client)
* PyTorch (опционально: очистка VRAM после транскрибации)

## Системные требования

* **Операционная система:** Windows 10 / 11 (64-bit)
* **Аппаратное обеспечение:** Дискретная видеокарта NVIDIA с объемом видеопамяти от 8 ГБ (рекомендуется RTX серия)
* **Программное обеспечение:**
* NVIDIA CUDA Toolkit (или pip-пакеты `nvidia-*` с CUDA DLL)
* Установленный и запущенный сервис Ollama

## Установка и настройка

### 1. Подготовка внешних компонентов

Установите сервис Ollama и загрузите рабочую модель:
```cmd
ollama pull gemma4-64k-q4:latest

```

### 2. Развертывание проекта

1. Клонируйте репозиторий или перейдите в корень проекта:
```cmd
cd Meeting_Assistant

```


2. Создайте и активируйте виртуальное окружение:
```cmd
python -m venv venv
call venv\Scripts\activate

```

Примечание: основной поддерживаемый рантайм — conda-окружение (base), которое
активирует `run.bat` (переменная `CONDA_ACTIVATE`). Системный Python 3.14 не
подходит: в нём отсутствуют CUDA DLL (cublas64_12.dll и т.п.) — при запуске вне
conda faster-whisper не загрузит модель. `src/main.py` частично компенсирует это
пропендивом conda/pip `nvidia-*` путей к PATH (`_ensure_cuda_dll_paths()`), но
гарантированно работает только conda-интерпретатор.


3. Установите зависимые библиотеки:
```cmd
pip install -r requirements.txt

```

### 3. Конфигурация (`.env` и `config.py`)

Все настройки задаются переменными окружения. Скопируйте `.env.example` в `.env` и при необходимости подставьте свои значения (без `.env` работают значения по умолчанию из `config.py`):

```cmd
copy .env.example .env

```

Основные параметры:

* `OBSIDIAN_DIR`: Абсолютный путь к целевой папке встреч в вашем Obsidian Vault.
* `WHISPER_MODEL_SIZE`: Размер модели Faster-Whisper (по умолчанию `large-v3`).
* `OLLAMA_MODEL`: Имя используемой модели в Ollama (по умолчанию `gemma4-64k-q4:latest`).
* `MIC_DEVICE` / `STEREO_MIX_DEVICE`: dshow-имена аудиоустройств по умолчанию (в интерфейсе можно выбрать другие).
* `SUMMARY_PROMPT_TEMPLATE`: Шаблон промпта саммари с плейсхолдерами `{subject}`, `{context}`, `{transcript}`.
* `ARCHIVE_RETENTION_DAYS`: Срок хранения аудио в `archive/` (по умолчанию 7 дней, 0 — не удалять).

Полный список переменных — в `.env.example`, значения по умолчанию — в `config.py`.

## Инструкция по запуску и эксплуатации

### Запуск приложения

Для запуска в фоновом режиме без открытия окна консоли используйте исполняемый скрипт:

```cmd
run.bat

```

Примечание: `run.bat` пытается активировать conda-окружение (путь задаётся переменной `CONDA_ACTIVATE` в скрипте); при его отсутствии используется `pythonw` из `PATH`.

Запуск с открытым окном консоли (окно UI то же, но ошибки запуска видны сразу):

```cmd
python src/main.py

```

Примечание: `src/main.py` перенаправляет stdout/stderr в `logs/app.log` (через
`SafeStreamWriter`), поэтому «живые» логи — в UI (вкладка логов) или в файле
`logs/app.log`, а не в консоли.

Доступен также headless-режим без графического интерфейса (только фоновая обработка очереди `inbox/`):

```cmd
python src/app.py

```

### Порядок работы

1. **Получение данных встречи:** Нажмите кнопку **«Из Outlook»**. Приложение найдет текущее или ближайшее событие в календаре и заполнит тему встречи.
2. **Запись:** Нажмите **«Начать запись»**. В папке `inbox/` сформируется `.wav` файл и `.json` с метаданными.
3. **Завершение записи:** Нажмите **«Остановить запись»**. Поток захвата корректно завершится и сохранит WAV-файл.
4. **Автоматическая обработка:** Фоновый воркер обнаружит файл в `inbox/`, запустит транскрибацию и сформирует саммари. По окончании файл переносится в `archive/`, а итоговый документ создается в целевой директории Obsidian.

## Структура каталогов

```text
Meeting_Assistant/
├── archive/              # Архив обработанных встреч по датам
├── inbox/                # Очередь нерасшифрованных аудиозаписей (.wav)
├── logs/                 # Логи работы приложения (app.log)
├── src/
│   ├── main.py           # Точка входа (UI), перенаправление логов
│   ├── app.py            # Headless-точка входа (без интерфейса)
│   ├── outlook_client.py # Взаимодействие с Outlook через MAPI
│   ├── recorder.py       # Захват аудио (PyAudioWPatch, WASAPI loopback)
│   ├── ui.py             # Интерфейс CustomTkinter
│   └── worker.py         # Фоновый поток транскрибации и саммаризации
├── tests/                # Модульные тесты и smoke-скрипты
├── config.py             # Значения по умолчанию, переопределяются через .env
├── .env.example          # Шаблон конфигурации (скопировать в .env)
├── requirements.txt      # Список зависимостей Python
└── run.bat               # Скрипт фонового запуска

```
